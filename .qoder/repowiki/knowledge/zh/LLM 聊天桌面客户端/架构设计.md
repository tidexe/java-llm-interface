- **分层架构**：采用经典的 MVC 变体结构。`com.llmchat.model` 定义数据实体（消息、会话、配置）；`com.llmchat.http` 封装网络通信与流式响应解析；`com.llmchat.config` 负责持久化存储；`com.llmchat.ui` 处理界面逻辑与用户交互。
- **入口与启动**：`App.java` 作为主入口，设置系统 LookAndFeel 并在 EDT 中启动 `MainFrame`。
- **UI 组合**：`MainFrame` 作为主窗口，通过 `JSplitPane` 组合侧边栏 `ChatListPanel` 和核心交互区 `ChatPanel`。
- **依赖方向**：UI 层依赖 Config 和 History 管理器进行状态同步；HTTP 客户端独立于 UI，通过回调接口 `StreamCallback` 异步通知 UI 更新。
- **关键组件**：`HttpClient` 实现 SSE (Server-Sent Events) 风格的流式读取；`ConfigManager` 使用 Java 原生序列化存储配置至 `.llmchat` 目录。
