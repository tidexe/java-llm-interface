- 自定义绘制组件：UI 组件（如 `ModernButton`, `MessageBubble`, `ChatItemPanel`）普遍重写 `paintComponent` 方法，使用 `Graphics2D` 和 `RoundRectangle2D` 实现圆角背景和抗锯齿渲染。
- 匿名内部类监听器：在组件初始化时广泛使用匿名内部类或 Lambda 表达式注册 `MouseListener` 和 `ActionListener`，以处理悬停、点击等交互状态。
- 手动 JSON 处理：在 `HttpClient` 中通过字符串拼接构建请求体，并通过索引查找和子串截取方式解析流式 JSON 响应，未引入第三方 JSON 库。
- EDT 线程安全：UI 更新操作（如 `MessageBubble.appendContent`）严格包裹在 `SwingUtilities.invokeLater` 中，确保在非 EDT 线程（如 HTTP 响应线程）接收数据时安全更新界面。
